# Foodplay2.0

FoodPlay is a personalized nutrition and meal-planning application built with Flask and Python.

## Features

- Calculates calorie and macronutrient requirements
- Supports activity- and sport-based nutrition estimates
- Uses food datasets to help generate meal recommendations
- Provides a Flask-based web interface and API endpoints

## Tech Stack

- Python
- Flask
- Pandas
- NumPy
- SciPy
- HTML/CSS

## Project Structure

- `app.py` — Flask application and API routes
- `calculator_functions.py` — nutrition and calorie calculations
- `helper_functions.py` — supporting application logic
- `templates/` — HTML templates
- `static/` — static assets
- CSV files — food and nutrient datasets

## Running Locally

Clone the repository and install the required Python dependencies, then run:

```bash
python app.py
```

The application will start using the Flask development server.
